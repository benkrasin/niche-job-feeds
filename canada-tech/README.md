# Tech roles in Canada

**1,142 open roles from 374 employers**, each first posted in the 30 days before 2026-10-26, taken from the employers' own career sites (Greenhouse, Lever, Ashby, Workable, SmartRecruiters, Recruitee, Workday public job APIs). Every row links straight to the employer's apply page; no other job board sits in between. 264 rows include a salary.
